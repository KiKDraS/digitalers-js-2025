📚 Diferencia entre module, defer y async

🎯 Resumen Rápido (TL;DR)

Atributo ¿Cuándo se ejecuta? ¿Mantiene orden? ¿Para qué sirve?
Ninguno Inmediatamente, bloquea la página - Scripts simples
async Cuando se descarga, sin orden ❌ No Scripts independientes
defer Después de HTML, mantiene orden ✅ Sí Scripts que necesitan DOM
module Como defer pero con módulos ES6 ✅ Sí Módulos JavaScript modernos

🧩 Explicación Detallada

1. Sin atributo (comportamiento normal)

<script src="script.js"></script>

¿Qué hace?

  • ⏸️ Detiene la carga de la página
  • 🚫 Bloqueante: El usuario ve una página en blanco
  • 🔢 Orden: Se ejecuta inmediatamente en orden

Cuando usarlo: Scripts pequeños esenciales.

2. async (Asíncrono)

<script async src="script.js"></script>

¿Qué hace?

  • ⚡ Descarga en segundo plano sin bloquear
  • 🎯 Ejecuta inmediatamente cuando se descarga
  • 🔀 Sin orden: Ejecuta en cualquier orden

Cuando usarlo: Scripts independientes como analytics.

3. defer (Diferido)

<script defer src="script.js"></script>

¿Qué hace?

  • ⚡ Descarga en segundo plano sin bloquear
  • ⏳ Ejecuta después del HTML
  • 📋 Mantiene el orden de ejecución

Cuando usarlo: Scripts que necesitan DOM o dependen de otros.

4. type="module" (Módulos ES6)

<script type="module" src="app.js"></script>

¿Qué hace?

  • 📦 Carga módulos JavaScript modernos
  • ⚡ Como defer pero con import/export
  • ✅ Mantiene el orden de ejecución
  • 🔒 Scope por módulo: variables no globales

Cuando usarlo: Aplicaciones modernas con módulos.

🎮 Analogía para entenderlo mejor

Sin atributo → Cajero que atiende de uno en uno
Todos hacen fila y esperan su turno. La tienda no funciona hasta que termine cada cliente.

async → Varios cajeros independientes
Cada cajero atiende cuando puede. No hay orden: el que termina primero sale primero.

defer → Pedidos para llevar
Tomas todos los pedidos primero. Preparas la comida después. Entregas en el mismo orden.

module → Restaurante organizado
Como defer pero con ingredientes importados de otros lugares. Todo bien organizado.

🚀 Recomendaciones Prácticas

Usa async para:

  • Analytics (Google Analytics)
  • Publicidad (AdSense)
  • Scripts de terceros independientes

Usa defer para:

  • Tus propios scripts
  • Scripts que necesitan el DOM
  • Scripts que dependen de otros scripts

Usa type="module" para:

  • Aplicaciones modernas
  • Cuando uses import/export
  • Proyectos nuevos con JavaScript moderno

Evita scripts sin atributos:

  • Solo para scripts críticos muy pequeños
  • Mejor usar defer en la mayoría de casos
