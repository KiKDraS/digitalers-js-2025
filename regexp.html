¿Qué son las Expresiones Regulares?

Las expresiones regulares (regex) son patrones que se utilizan para hacer coincidir combinaciones de caracteres en cadenas de texto. Son como "fórmulas mágicas" para buscar, validar y manipular texto.

1. Sintaxis Básica de Regex

Las regex se escriben entre barras /patrón/ o se crean con el constructor new RegExp().

// Forma literal (recomendada)
const regex1 = /abc/;

// Usando constructor
const regex2 = new RegExp('abc');

// Con flags (banderas)
const regex3 = /abc/i; // 'i' para case-insensitive
const regex4 = /abc/g; // 'g' para búsqueda global
📝 Flags más comunes:
  • i - Ignorar mayúsculas/minúsculas
  • g - Búsqueda global (todas las coincidencias)
  • m - Multilínea
2. Caracteres Especiales y Metacaracteres

Los caracteres especiales dan superpoderes a tus búsquedas:

. - Cualquier carácter (excepto nueva línea)
\d - Cualquier dígito (0-9)
\w - Cualquier carácter de palabra (a-z, A-Z, 0-9, _)
\s - Cualquier espacio en blanco
^ - Inicio de la cadena
$ - Fin de la cadena
[abc] - Cualquier carácter entre los brackets
[a-z] - Cualquier carácter en el rango
(abc) - Grupo de caracteres

3. Cuantificadores: Especificando Cantidades

Los cuantificadores controlan cuántas veces aparece un carácter o grupo:

* - 0 o más veces
+ - 1 o más veces
? - 0 o 1 vez (opcional)
{n} - Exactamente n veces
{n,} - n o más veces
{n,m} - Entre n y m veces

4. Usos Comunes de Regex

Las regex son increíblemente útiles para:

✅ Validación de formularios:
// Email
/^[^\s@]+@[^\s@]+\.[^\s@]+$/

// Teléfono (ejemplo simple)
/^\d{9}$/
🔍 Búsqueda y extracción:
// Extraer precios
/\$\d+\.\d{2}/

// Buscar fechas
/\d{2}\/\d{2}\/\d{4}/
