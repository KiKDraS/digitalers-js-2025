Técnicas del DOM para Principiantes

Aprende las mejores prácticas para manipular el Document Object Model

¿Qué es el DOM?

El DOM (Document Object Model) es una representación estructurada de tu documento HTML. Piensa en él como un árbol de nodos donde cada elemento, atributo y texto es un objeto que puedes manipular con JavaScript.

1. Buscar elementos con .querySelector() y .querySelectorAll()

Estos métodos te permiten buscar elementos usando selectores CSS, lo que los hace muy flexibles.

// Buscar el primer elemento con clase 'mi-clase'
const elemento = document.querySelector('.mi-clase');

// Buscar todos los elementos de tipo div
const elementos = document.querySelectorAll('div');

2. Buscar padres con .closest()

Este método te permite buscar el ancestro (elemento padre) más cercano que coincida con un selector.

// Desde un elemento, encontrar el div padre más cercano
const divPadre = elemento.closest('div');

3. Manipular clases con .classList

classList proporciona métodos para add, eliminar y alternar clases CSS de un elemento.

// add una clase
elemento.classList.add('clase-activa');

// Eliminar una clase
elemento.classList.remove('clase-activa');

// Alternar una clase (si existe la quita, si no existe la añade)
elemento.classList.toggle('clase-activa');

Ventaja: classList es más limpio y potente que usar className directamente.
4. Usar .textContent en lugar de .innerText

textContent es más eficiente y predecible que innerText.

// Cambiar el texto de un elemento
elemento.textContent = 'Nuevo texto';
Demo:
Texto original
Diferencia: innerText tiene en cuenta el estilo y no devuelve texto oculto, mientras que textContent devuelve todo el texto incluido el oculto.
5. Manipulación segura de HTML (evitar innerHTML)

El uso de innerHTML puede ser peligroso porque permite la inyección de código malicioso. En su lugar, se recomienda usar métodos seguros o sanitizar el contenido.

// ❌ Evitar esto si el contenido es dinámico
elemento.innerHTML = contenidoDinamico;

// ✅ Usar textContent para texto plano
elemento.textContent = contenidoDinamico;

// ✅ O usar APIs seguras como DOMPurify para sanitizar
elemento.innerHTML = DOMPurify.sanitize(contenidoDinamico);
Demo:
Contenido original
Advertencia: Nunca uses innerHTML con contenido que provenga del usuario sin sanitizar. Existen librerías como DOMPurify para sanitizar HTML.
Futuro: Próximamente tendremos .setHTML() con sanitización integrada.
6. Métodos modernos para manipular elementos

Los métodos append(), prepend(), before() y after() son más flexibles que los tradicionales.

// add un elemento al final
padre.append(nuevoElemento);

// add un elemento al principio
padre.prepend(nuevoElemento);

// add un elemento antes de otro
elementoExistente.before(nuevoElemento);

// add un elemento después de otro
elementoExistente.after(nuevoElemento);

7. Cambiar estilos con .style.setProperty()

Este método es más consistente para cambiar estilos, especialmente con propiedades que tienen guiones.

// Cambiar el color de fondo
elemento.style.setProperty('background-color', 'red');

// También funciona para variables CSS
elemento.style.setProperty('--mi-variable', '100px');
Demo:
Este elemento cambiará de estilo
Ventaja: Con setProperty puedes cambiar variables CSS, lo que no es posible con la notación de punto.

Conclusión

Aunque los frameworks modernos abstractan muchas de estas operaciones, entender cómo funciona el DOM te dará un mejor control sobre tus aplicaciones web y te ayudará a debuggar problemas más eficientemente.

Practica estas técnicas y pronto se convertirán en parte natural de tu flujo de trabajo como desarrollador frontend.
