🏗️ POO en JavaScript: De Prototipos a Clases ES6

🎯 ¿Qué es la POO en JavaScript?

JavaScript usa prototipos en lugar de clases tradicionales. ES6 introdujo la sintaxis de class que es "azúcar sintáctico" sobre el sistema de prototipos.

📜 Evolución: Antes vs Después de ES6

🚀 ANTES de ES6 (Prototipos)

                    
                        

                            // CONSTRUCTOR FUNCTION
                            function Persona(nombre, edad) {
                                this.nombre = nombre;
                                this.edad = edad;
                            }

                            // MÉTODOS EN EL PROTOTIPO
                            Persona.prototype.saludar = function() {
                                return `Hola, soy ${this.nombre} y tengo ${this.edad} años`;
                            };

                            // HERENCIA CON PROTOTIPOS
                            function Estudiante(nombre, edad, curso) {
                                Persona.call(this, nombre, edad);
                                this.curso = curso;
                            }

                            Estudiante.prototype = Object.create(Persona.prototype);
                            Estudiante.prototype.constructor = Estudiante;

                            Estudiante.prototype.estudiar = function() {
                                return `${this.nombre} está estudiando ${this.curso}`;
                            };

                            // USO
                            const ana = new Estudiante("Ana", 20, "JavaScript");
                            console.log(ana.saludar()); // "Hola, soy Ana..."
                            console.log(ana.estudiar()); // "Ana está estudiando..."

✅ DESPUÉS de ES6 (Clases)

                    
                        

                            // CLASE CON SYNTAX MODERNA
                            class Persona {
                                constructor(nombre, edad) {
                                    this.nombre = nombre;
                                    this.edad = edad;
                                }

                                saludar() {
                                    return `Hola, soy ${this.nombre} y tengo ${this.edad} años`;
                                }
                            }

                            // HERENCIA CON EXTENDS
                            class Estudiante extends Persona {
                                constructor(nombre, edad, curso) {
                                    super(nombre, edad); // Llama al constructor padre
                                    this.curso = curso;
                                }

                                estudiar() {
                                    return `${this.nombre} está estudiando ${this.curso}`;
                                }
                            }

                            // USO (IGUAL QUE ANTES)
                            const ana = new Estudiante("Ana", 20, "JavaScript");
                            console.log(ana.saludar()); // "Hola, soy Ana..."
                            console.log(ana.estudiar()); // "Ana está estudiando..."

🔍 Puntos Clave a Tener en Cuenta

⚠️ ¡IMPORTANTE! Las clases en JS son funciones

                
                    

                        class Persona {}
                        console.log(typeof Persona); // "function" ✅
                        console.log(Persona.prototype); // Existe el prototipo

💡 El operador `new` es crucial

                
                    

                        // ✅ CORRECTO
                        const persona = new Persona("Juan", 25);

                        // ❌ ERROR - this será undefined o global
                        const personaMala = Persona("Juan", 25);

📊 Diferencias Principales

Característica Prototipos (Pre-ES6) Clases (ES6+)
Sintaxis Más verbosa Más clara y familiar
Herencia Object.create() y prototype extends y super
Métodos estáticos Constructor.metodo = function() {} static metodo() {}
Getters/Setters Object.defineProperty() get/set en la clase
Funcionamiento real ¡SON LO MISMO! Las clases son "azúcar sintáctico"

🚀 Conceptos Avanzados

            
                

                    // MÉTODOS ESTÁTICOS
                    class Matematica {
                        static sumar(a, b) {
                            return a + b;
                        }

                        static PI = 3.1416;
                    }

                    // Se llama en la clase, no en instancias
                    console.log(Matematica.sumar(2, 3)); // 5
                    console.log(Matematica.PI); // 3.1416

                    // GETTERS Y SETTERS
                    class Cuenta {
                        constructor(saldo) {
                            this._saldo = saldo;
                        }

                        get saldo() {
                            return this._saldo;
                        }

                        set saldo(nuevoSaldo) {
                            if (nuevoSaldo >= 0) {
                                this._saldo = nuevoSaldo;
                            }
                        }
                    }

                    const miCuenta = new Cuenta(100);
                    miCuenta.saldo = 200; // Usa el setter
                    console.log(miCuenta.saldo); // Usa el getter

🎯 Buenas Prácticas

  1. Usa clases ES6 - Son más legibles y menos propensas a errores
  2. Siempre usa `new` - Excepto en factories functions
  3. Métodos en el prototype - Las clases lo hacen automáticamente
  4. Herencia con `extends` - Mucho más simple que con prototipos
  5. Encapsulación - Usa convención _ para propiedades "privadas"
