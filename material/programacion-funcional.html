🎯 Funciones Puras

Las funciones puras siempre devuelven el mismo resultado para los mismos argumentos y no tienen efectos secundarios.


                        // ✅ FUNCIÓN PURA
                        function sumar(a, b) {
                          return a + b;
                        }
                        

                        // ❌ FUNCIÓN IMPURA
                        let contador = 0;
                        function incrementar() {
                          contador++; // Efecto secundario!
                          return contador;
                        }

🔄 Inmutabilidad

Los datos no se modifican, se crean nuevos datos. Como trabajar con documentos: no borras el original, creas una copia con cambios.


                        // ❌ MUTACIÓN (Malo)
                        const array = [1, 2, 3];
                        array.push(4); // Modifica el original
                        

                        // ✅ INMUTABILIDAD (Bueno)
                        const array = [1, 2, 3];
                        const nuevoArray = [...array, 4]; // Nuevo array
                        
                        console.log(array); // [1, 2, 3] ← Original intacto!
                        console.log(nuevoArray); // [1, 2, 3, 4]

🎭 First-Class Functions

Las funciones son tratadas como cualquier otro valor: pueden ser asignadas a variables, pasadas como argumentos y retornadas desde otras funciones.


                        // Las funciones son ciudadanas de primera clase
                        const duplicar = x => x * 2;
                        const triplicar = x => x * 3;
                        

                        // Función que acepta otra función
                        function aplicarOperacion(numero, operacion) {
                          return operacion(numero);
                        }
                        
                        console.log(aplicarOperacion(5, duplicar)); // 10
                        console.log(aplicarOperacion(5, triplicar)); // 15

⚔️ Imperativo vs Funcional

Compara cómo resolveríamos el mismo problema de dos maneras diferentes:

🔧 Estilo Imperativo

"CÓMO hacerlo" - Paso a paso

// Duplicar números pares de un array
const numeros = [1, 2, 3, 4, 5];
const resultado = [];

for (let i = 0; i < numeros.length; i++) {
  if (numeros[i] % 2 === 0) {
    resultado.push(numeros[i] * 2);
  }
}

console.log(resultado); // [4, 8]

🎨 Estilo Funcional

"QUÉ queremos" - Declarativo

// Duplicar números pares de un array
const numeros = [1, 2, 3, 4, 5];

const resultado = numeros
  .filter(n => n % 2 === 0)
  .map(n => n * 2);

console.log(resultado); // [4, 8]

🛠️ Las 3 Super Herramientas de la PF

🗺️ map()

"Transforma cada elemento"

[1, 2, 3].map(x => x * 2)
// → [2, 4, 6]

🔍 filter()

"Filtra elementos"

[1, 2, 3, 4].filter(x => x > 2)
// → [3, 4]

🧮 reduce()

"Reduce a un valor"

[1, 2, 3].reduce((acc, x) =>
  acc + x, 0)
// → 6

// Pipeline funcional - Cadena de operaciones
const resultado = productos
  .filter(producto => producto.categoria === 'fruta')
  .map(producto => ({
    ...producto,
    precioConImpuesto: producto.precio * 1.16
  }))
  .reduce((total, producto) =>
    total + producto.precioConImpuesto, 0);

console.log(resultado); // 4.64

✅ Ventajas

  • Código predecible: Mismas entradas = mismas salidas
  • Fácil de testear: Sin dependencias externas
  • Menos bugs: Sin efectos secundarios sorpresa
  • Más mantenible: Código claro y declarativo
  • Escalable: Fácil de paralelizar

  • Transformaciones complejas
  • Aplicaciones concurrentes
  • Donde la predecibilidad es clave
  • Sistemas de alta confiabilidad
